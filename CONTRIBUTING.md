# Contributing to AY Pilot Native

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/AY-PiLot.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Commit: `git commit -m "feat: description"`
6. Push: `git push origin feature/your-feature`
7. Create a Pull Request

## Code Style

- **C++:** Google C++ Style Guide
- **Kotlin:** Kotlin Coding Conventions
- **JavaScript:** Prettier (configured)
- **Python:** PEP 8

## Testing

Add tests for new features and ensure all tests pass before submitting PR.

## Questions?

Open a discussion in GitHub Discussions.
